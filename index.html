2. Name it (e.g. team-hub) → set Public → Create repository

3. Click "uploading an existing file" → drag your index.html in

4. Type commit message → click Commit changes

5. Go to Settings → Pages → Source: main / root → Save

6. Wait 1–2 min → your URL: https://USERNAME.github.io/REPONAME

7. Paste that URL above → Regenerate QR
